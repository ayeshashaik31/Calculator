# 🧮 Calculator App

A simple and responsive calculator built using **HTML, CSS, and JavaScript**.

## 🚀 Features

* Basic arithmetic operations
* Addition, subtraction, multiplication, and division
* Decimal number support
* Clear button
* Delete/backspace functionality
* Keyboard support
* Interactive button effects
* Responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* DOM Manipulation
* Keyboard Events

## 📂 Project Structure

```text
Calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🎯 How It Works

The calculator uses JavaScript to handle button clicks and keyboard input.

* Number and operator buttons are displayed on the calculator screen.
* `=` evaluates the entered expression.
* `C` clears the display.
* `X` deletes the last character.
* Keyboard keys can also be used to perform calculations.

## 💻 How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
